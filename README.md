# patversmes-parvaldibas-platforma
Kvalifikācijas darbs specialitātei “Programmēšanas tehniķis”, Rīgas Valsts tehnikums, Datorikas nodaļa.

Tēma: Tīmekļa platforma mājdzīvnieku patversmes darba organizēšanai, brīvprātīgo uzskaitei un dzīvnieku adopcijas pārvaldībai.

## Projekta apraksts

Platforma apvieno patversmes ikdienas darba procesus vienā sistēmā: brīvprātīgo maiņu plānošanu, dzīvnieku uzskaiti, adopcijas pieteikumu apstrādi, krājumu uzskaiti un atskaišu ģenerēšanu. Sistēmai ir publiskā daļa (dzīvnieku katalogs) un slēgtā daļa (darbs pēc lietotāju lomām).

## Lietotāju lomas
- Apmeklētājs
- Brīvprātīgais
- Koordinators
- Administrators
## Plānotie obligātie moduļi
1. Lietotāju reģistrācija un pieteikšanās ar lomām
2. Brīvprātīgo maiņas, pieteikšanās un stundu uzskaite
3. Dzīvnieku kartīšu pārvaldība
4. Publisks dzīvnieku katalogs ar filtrēšanu
5. Adopcijas pieteikumi ar statusiem
6. Barības un medikamentu krājumu uzskaite
7. PDF atskaites un dokumenti, e-pasta paziņojumi
## Plānotās tehnoloģijas
- PHP, Laravel
- MySQL
- HTML5, CSS, JavaScript, Bootstrap
- DomPDF
- Visual Studio Code, Laragon, Composer, Git
## Stāvoklis

Projekts atrodas sākuma stadijā: ir izstrādāta projekta koncepcija, programmas kods tiks pievienots prakses laikā.
